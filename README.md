# EduClip AI

## AI-Powered Educational Video Content Curator

EduClip AI is a web application designed to discover educational content
and transform selected video content into short-form educational clips.

The system combines artificial intelligence, video processing, speech
transcription, and a web-based interface into one automated workflow.

---

## Project Objective

The main objective of EduClip AI is to provide an intelligent pipeline
that can:

1. Generate 100 educational topics using AI.
2. Discover relevant video content for selected topics.
3. Transcribe video audio into timestamped text.
4. Allow users to select useful portions of the transcript.
5. Generate short-form educational video clips.
6. Add subtitles and format videos for vertical short-form platforms.
7. Provide AI-generated titles, hooks, captions, and hashtags.
